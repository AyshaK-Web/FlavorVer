# **App Name**: FlavorVerse

## Core Features:

- Recipe Search: Allows users to find recipes by ingredient or cuisine.
- Recipe Details: Displays comprehensive instructions, images, and nutritional information for each recipe.
- Favorites: Enables users to save and organize their favorite recipes.
- Dietary Filter: Filters recipes based on dietary restrictions and preferences such as vegetarian, vegan, gluten-free, etc.
- Smart Substitution Suggestions: Suggests ingredient substitutions based on dietary restrictions or availability, powered by AI.

## Style Guidelines:

- Primary color: Warm terracotta (#E07A5F), reminiscent of cooking and earth.
- Background color: Light beige (#F8F0E3) for a clean and inviting feel.
- Accent color: Mustard yellow (#F2CC8F), analogous to terracotta but providing contrast.
- Body font: 'PT Sans', a clean, friendly sans-serif, ideal for recipe details and instructions.
- Headline font: 'Belleza' for titles, conveying style related to art and design. For longer text, use 'Alegreya'.
- Use line icons related to cooking and food ingredients for key actions and filters.
- Clean, card-based layout to present recipes in a visually appealing and easily digestible format.
